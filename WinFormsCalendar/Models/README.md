# Models — 데이터 모양

화면이 아니라 **데이터가 어떤 값으로 이루어져 있는지**를 정의하는 클래스를 둡니다.

| 파일 | 구분 | 하는 일 | 사용하는 곳 | 브랜치 |
|---|---|---|---|---|
| `Schedule.cs` | 필수 | 일정 한 개가 담을 값(날짜, 시작 시간·분, 제목, 메모, 카테고리, 첨부 파일 경로, D-day 표시 여부) | 메인 화면(목록 표시), `ScheduleForm`(입력), `DataStore`(저장) | `feature/schedule` |

- 지금은 빈 클래스입니다. 어떤 값을 담을지는 [설계 문서](../../docs/설계.md)를 참고하세요.
- 네임스페이스는 항상 `WinFormsCalendar`입니다.
