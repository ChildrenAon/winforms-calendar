# 기능 명세

팀 합의(계획 발표 기준)로 정리한 기능 목록입니다. 진행 상태는 작업하면서 갱신합니다.

> **담당과 작업 파일은 [작업가이드.md](작업가이드.md)의 표에서만 관리합니다.** 두 곳에 적으면 서로 어긋나기 때문에 이 문서에는 담당을 적지 않습니다.

## 필수 기능

| 기능 | 설명 | 상태 |
|---|---|---|
| 기본 달력 틀 | 월 단위 달력 화면, 이전/다음 달 이동 | 예정 |
| 현재 날짜 표기 | 오늘 날짜 강조 | 예정 |
| 일정 등록·수정·삭제 | 날짜별 일정 관리 | 예정 |

## 추가 기능

| 기능 | 설명 | 상태 |
|---|---|---|
| 저장·불러오기 | 일정을 파일에 저장하고 실행 시 불러오기 | 예정 |
| 시간/분 설정 | 일정 등록 시 시간과 분 지정 | 예정 |
| 파일 첨부 | 일정에 파일 경로 연결 | 예정 |
| 카테고리별 색상 | 카테고리마다 색을 지정 | 예정 |
| 키워드 검색 | 키워드가 포함된 일정 찾기 | 예정 |
| D-day | 지정한 날짜까지 남은 기간을 달력 화면에 표시 | 예정 |
| 타임캡슐 메시지 | 일정으로는 안 보이고, 지정한 날짜가 되면 뜨는 메시지 | 예정 |
| 잔디 심기 | 활동 시간을 기록하면 그 날짜 칸의 색이 진해짐 | 예정 |
| 미니 위젯 모드 | 달력 창을 화면 구석에 작게 띄우기 | 예정 |

상태 표기: 예정 → 작업 중 → 완료
