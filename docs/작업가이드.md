# 작업 가이드

"내 기능은 어떤 파일에서 작업하지?"를 한눈에 보기 위한 문서입니다. 파일은 이미 만들어져 있고 `.csproj`에도 등록돼 있으니, **자기 파일만 열어서 채우면 됩니다.**

## 기능 → 파일 → 브랜치

| 기능 | 작업할 파일 | 브랜치 이름 | 담당 |
|---|---|---|---|
| 달력 틀, 오늘 표시, 월 이동 | `MainForm.cs` | `feature/calendar` | ChildrenAon |
| 일정 등록·수정·삭제 (시간, 카테고리 색, 파일 첨부, D-day 포함) | `Forms/ScheduleForm.cs`, `Models/Schedule.cs` | `feature/schedule` | ChildrenAon |
| 저장·불러오기 | `Data/DataStore.cs` | `feature/save-load` | 미정 |
| 키워드 검색 | `Forms/SearchForm.cs` | `feature/search` | 미정 |
| 타임캡슐 메시지 | `Forms/TimeCapsuleForm.cs` | `feature/time-capsule` | 미정 |
| 잔디 심기 | `Forms/GrassForm.cs` (칸 색 칠하기는 `MainForm.cs`) | `feature/grass` | 미정 |
| 미니 위젯 모드 | `Forms/MiniWidgetForm.cs` | `feature/mini-widget` | 미정 |

담당이 정해지면 위 표와 각 파일 맨 위 주석의 `담당`을 같이 고칩니다.

## 폴더 설명

| 폴더 | 들어가는 것 |
|---|---|
| `WinFormsCalendar/` (바로 아래) | `Program.cs`, 메인 화면 `MainForm` |
| `Forms/` | 창(폼) 하나당 파일 하나. 새 창은 여기에 만든다 |
| `Models/` | 데이터 모양을 정의하는 클래스 (예: `Schedule`) |
| `Data/` | 파일 저장·불러오기 같은 데이터 처리 |
| `docs/` | 기능 명세, 설계, 발표 분량, 이 문서 |

## 작업 순서

```bash
git clone https://github.com/ChildrenAon/winforms-calendar.git
git checkout -b feature/search          # 내 기능 브랜치 만들기 (이름은 위 표 참고)
```

Visual Studio에서 `WinFormsCalendar.sln`을 열고 내 파일을 채웁니다. 다 되면:

```bash
git add .
git commit -m "검색 창 기본 화면 추가"
git push -u origin feature/search
```

그다음 GitHub 저장소 페이지에서 **Pull Request**를 만들면 `ChildrenAon`이 확인하고 `main`에 합칩니다. Visual Studio의 Git 변경 사항 창으로 해도 같습니다.

## 지켜야 할 것

1. **`MainForm.cs`는 `ChildrenAon`이 담당합니다.** 다른 분이 만든 창을 메인 화면에서 여는 코드는, 해당 창이 완성되면 한 줄만 추가하는 방식으로 하고 미리 알려 주세요. 같은 파일을 동시에 고치면 충돌이 납니다.
2. **네임스페이스는 항상 `WinFormsCalendar`입니다.** Visual Studio가 새 파일을 만들 때 `WinFormsCalendar.Forms`처럼 폴더 이름을 붙이는 경우가 있는데, 지우고 `WinFormsCalendar`로 맞춥니다.
3. **파일 맨 위 주석을 유지합니다.** 하는 일과 참고한 수업 주차를 갱신해 두면 발표 준비에 그대로 쓸 수 있습니다. 수업에 없는 문법을 썼다면 `참고 수업`에 적어 둡니다.
4. **한글 주석**을 충분히 답니다. 컨트롤 이름은 `btnAdd`, `lblDate`처럼 역할이 보이게 짓습니다.
5. 새 파일을 추가하면 `WinFormsCalendar.csproj`가 바뀝니다. 충돌이 나면 양쪽에 추가된 줄을 **둘 다 남기면** 됩니다.

## 새 창을 더 만들어야 할 때

`Forms` 폴더를 우클릭 → 추가 → 새 항목 → Windows Forms → 폼(Windows Forms)을 고르고 이름을 `XxxForm`으로 짓습니다. 만들어진 뒤 네임스페이스를 `WinFormsCalendar`로 고치고, 이 문서의 표에 한 줄을 추가합니다.
