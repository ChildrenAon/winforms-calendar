# 설계

구현한 내용에 맞춰 정리한 문서입니다. 팀에서 아직 정하지 않은 부분은 "제안"이라고 표시했습니다.

## 달력 칸에 보이는 것

- **칸 바탕색**은 잔디 기록이 사용합니다. 그날 활동 시간을 모두 더해 4단계로 칠합니다. (1시간 미만 / 2시간 미만 / 4시간 미만 / 4시간 이상, 진할수록 오래 한 날)
- **일정**은 칸 안의 작은 점으로 보여줍니다. 점 색은 그 일정의 카테고리 색이고, 최대 4개까지 찍고 넘치면 `+2`처럼 표시합니다.
- **오늘**은 날짜 숫자가 파란 바탕에 흰 글자, **선택한 날**은 칸 테두리가 파랗게 보입니다.
- 이번 달이 아닌 날은 연한 회색으로 보이고, 누르면 그 달로 이동합니다.

## 데이터 (Models 폴더)

| 클래스 | 담는 값 | 쓰는 곳 |
|---|---|---|
| `Schedule` 일정 | 날짜, 시, 분, 제목, 메모, 카테고리 이름, 첨부 파일 경로, D-day 표시 여부 | 메인 화면, 일정 창 |
| `Category` 카테고리 | 이름, 색 | 일정 창(분류·색 지정), 메인 화면(점·글자 색) |
| `Capsule` 타임캡슐 | 열어볼 날짜, 메시지, 이미 열어 봤는지 | 타임캡슐 창 |
| `GrassRecord` 잔디 기록 | 날짜, 활동 이름, 시간(분) | 잔디 창, 메인 화면(칸 색) |

- D-day는 별도 항목이 아니라 일정의 속성입니다. 메인 화면 오른쪽 아래에 오늘 이후의 D-day 일정이 가까운 순서로 `D-3  제목  (11/12)`처럼 보입니다.
- 카테고리는 처음에 기본 5개(기본·학업·약속·운동·기타)가 만들어지고, 색은 일정 창의 [색 지정]으로 바꿉니다.
- 첨부 파일은 복사하지 않고 경로만 저장합니다.

## 저장 방식

- 한 파일(`data\calendar.txt`)에 한 줄에 한 항목씩, `|`로 구분해 저장합니다. 맨 앞 글자가 종류입니다.

```
K|카테고리 이름|색
S|날짜|시|분|제목|메모|카테고리|첨부 파일 경로|D-day(1/0)
C|날짜|메시지|열어 봄(1/0)
G|날짜|활동 이름|분
```

- 제목이나 메모에 `|`나 줄바꿈이 들어가면 줄이 깨지므로 `\p`, `\n` 같은 글자로 바꿔 저장하고 읽을 때 되돌립니다.
- 위치는 실행 폴더의 `data/`, 인코딩은 UTF-8입니다. 일정을 추가·수정·삭제하거나 카테고리 색을 바꿀 때마다 바로 저장합니다.
- 파일의 일부 줄이 깨져 있어도 나머지는 읽습니다.

## 화면 구성 (메인)

- 상단: 년/월, 이전·다음 달(`<` `>`), 오늘
- 왼쪽: 6줄×7칸 날짜 칸 (한 번 누르면 날짜 선택, 두 번 누르면 그 날짜에 일정 추가)
- 오른쪽: 선택한 날짜, 그날의 일정 목록, [추가] [수정] [삭제], D-day 목록
- 아래: [검색] [타임캡슐] [잔디 기록] 버튼 (각 창은 담당자가 채웁니다)

## 폼 사이의 데이터 전달

수업 5주차(`Form2(this)`)와 같은 방식입니다.

- 메인 화면이 데이터 목록을 갖고, 다른 창을 열 때 **메인 화면 자신(`this`)을 넘깁니다.**
- 각 창은 `m_Parent`로 받아서 `m_Parent.Schedules`, `m_Parent.Capsules`, `m_Parent.GrassRecords`, `m_Parent.Categories`로 꺼내 씁니다.
- 데이터를 고친 창은 `m_Parent.SaveAll()`로 저장합니다. 창이 닫히면 메인 화면이 화면을 다시 그립니다.
- 일정 창은 결과를 `Result` 프로퍼티로 돌려줍니다. (수업 5·7주차 `LoginCheck`와 같은 방식)

## 구현 순서와 진행 상태

계획 발표에서 말한 대로 **필수 → 추가** 순서로 먼저 만들고, 확장은 여유가 되면 만듭니다.

| 순서 | 만들 것 | 구분 | 상태 |
|---|---|---|---|
| 1 | 뼈대 + 달력 칸 + 오늘 표시 | 필수 | 구현됨 |
| 2 | 일정 등록·수정·삭제 | 필수 | 구현됨 |
| 3 | 시간/분 설정, 파일 첨부 | 추가 | 구현됨 |
| 3 | 타임캡슐 메시지 (창 안은 담당자가 채움) | 추가 | 예정 |
| 4 | 저장·불러오기 | 확장 | 구현됨 |
| 5 | 키워드 검색, 잔디 기록 입력 (창 안은 담당자가 채움) | 확장 | 예정 |
| 6 | 카테고리 색, D-day | 확장 | 구현됨 |
| 6 | 미니 위젯 | 확장 | 예정 |

- 저장·불러오기는 확장 아이디어이지만 앞당겨 만들었습니다. (제안) 타임캡슐은 날짜가 지나야 뜨는 기능이라 프로그램을 껐다 켜도 데이터가 남아 있어야 의미가 있기 때문입니다.
- 잔디는 "달력 칸 색 칠하기"까지 구현되어 있고, 기록을 입력하는 `GrassForm` 안쪽이 남아 있습니다.
- 시연은 1분 내외 영상으로 하므로, 필수·추가 기능을 안정적으로 만드는 것이 먼저입니다.
