# 발표 분량

최종 발표에서 파일(기능)별로 누가 설명할지 정리하는 표입니다. 코드가 만들어지는 대로 "한 줄 설명"과 "설명 담당"을 채웁니다.

| 파일 | 한 줄 설명 | 주로 쓰는 수업 내용 | 설명 담당 |
|---|---|---|---|
| `Program.cs` | 프로그램 시작점, 메인 폼 실행 | 3주차 폼 기본 | |
| `MainForm.cs` | 메인 화면(달력) | | |
| `Forms/ScheduleForm.cs` | 일정 등록·수정 창 | 5주차 모달 폼, 6주차 대화상자 | |
| `Forms/SearchForm.cs` | 키워드 검색 창 | 9주차 ListView | |
| `Forms/TimeCapsuleForm.cs` | 타임캡슐 메시지 창 | 9주차 Timer | |
| `Forms/GrassForm.cs` | 잔디 기록 창 | 9주차 NumericUpDown | |
| `Forms/MiniWidgetForm.cs` | 미니 위젯 모드 창 | 4주차 Location·Size | |
| `Models/Schedule.cs` | 일정 데이터 | | |
| `Data/DataStore.cs` | 파일 저장·불러오기 | 6주차 File 입출력 | |

설명할 때 확인할 것

- 이 파일이 **무슨 일을 하는지** 한두 문장으로 말할 수 있는가
- 사용한 컨트롤과 이벤트가 **수업의 어떤 주차 내용**인가
- 수업에 없던 문법(예: `DateTime`)은 어떤 역할인지 설명할 수 있는가
