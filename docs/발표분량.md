# 발표 분량

최종 발표에서 **누가 무엇을 설명할지** 정리한 문서입니다. 실명 대신 역할 이름이나 GitHub 아이디로 적습니다. 코드를 만든 담당은 [작업가이드.md](작업가이드.md)의 표에서 따로 관리합니다.

## 역할

| 담당 | 맡는 일 |
|---|---|
| 발표 담당 | 시작과 마무리, 전체 구조 설명(간단히), 시연 영상 흐름 설명, 발표 전반 진행 |
| PPT 담당 | PPT 제작, 시연 영상(1분 내외) 촬영. 저장 방식은 JSON이나 DB가 아닌 **텍스트 파일**로 적기 |

## 발표 순서

발표 담당(시작 → 시연 영상 → 구조와 데이터) → `ChildrenAon` → 공통 담당 → `WhelkMono` → PPT 담당 → 발표 담당(마무리)

## 코드 설명 분담

함수 이름은 파일을 열고 Ctrl+F로 찾습니다.

| 설명 담당 | 설명할 내용 | 파일과 함수 |
|---|---|---|
| 발표 담당 | 프로그램 시작, 데이터 모양 | `Program.cs`, `Models/` 폴더의 `Schedule.cs`·`Category.cs`·`Capsule.cs`·`GrassRecord.cs` |
| `ChildrenAon` | 달력 화면 | `MainForm.cs`: `BuildCalendar`, `RefreshCalendar`, `bt_Prev_Click`, `bt_Next_Click`, `bt_Today_Click`, `Cell_Click` |
| 공통 담당 | 일정 등록·수정 창 | `Forms/ScheduleForm.cs` |
| 공통 담당 | 일정 목록, 추가·수정·삭제 | `MainForm.cs`: `RefreshScheduleList`, `GetSchedules`, `CompareSchedule`, `bt_Add_Click`, `bt_Edit_Click`, `bt_Delete_Click`, `OpenScheduleForm`, `GetSelectedSchedule` |
| 공통 담당 | D-day | `MainForm.cs`: `RefreshDday`, `CompareByDate` |
| 공통 담당 | 잔디 | `Forms/GrassForm.cs`, `MainForm.cs`: `GetGrassMinutes`, `GetGrassLevel`, `GetGrassColor` |
| `WhelkMono` | 타임캡슐 | `Forms/TimeCapsuleForm.cs` |
| `WhelkMono` | 저장·불러오기 | `Data/DataStore.cs` |
| PPT 담당 | 키워드 검색 | `Forms/SearchForm.cs` |
| PPT 담당 | 미니 위젯 | `Forms/MiniWidgetForm.cs` |

## 수업 내용과 연결

각 파일 맨 위 주석을 옮긴 것입니다. 번호 표기(주차, 장)는 파일에 적힌 그대로입니다.

| 파일 | 한 줄 설명 | 수업에서 배운 것 | 수업에 없던 것 |
|---|---|---|---|
| `Program.cs` | 프로그램 시작점, 메인 화면 실행 | 3주차 폼 기본 | |
| `Models/` | 일정·카테고리·캡슐·잔디 기록의 데이터 모양 | 5·7주차 get/set 프로퍼티 | |
| `MainForm.cs` | 메인 화면(달력, 일정 목록, D-day) | 4주차 위치·색, 5주차 모달 폼, 9주차 ListView·ListBox | `DateTime` 계산, `for`로 칸 만들기, `List<T>`, `Sort` |
| `Forms/ScheduleForm.cs` | 일정 등록·수정 창 | 5주차 모달 폼·ComboBox, 6주차 파일·색 대화상자, 9주차 NumericUpDown | |
| `Forms/GrassForm.cs` | 잔디 기록 창 | 5주차 모달 폼, 9주차 NumericUpDown·ListView | |
| `Forms/TimeCapsuleForm.cs` | 타임캡슐 창과 자동 팝업 | 6장 Timer·ListView | DateTimePicker, `static`, `List<T>`, `DllImport` |
| `Data/DataStore.cs` | 파일 저장·불러오기 | 6주차 파일 읽기·쓰기, try-catch | `ReadAllLines`·`WriteAllLines`, `Split` |
| `Forms/SearchForm.cs` | 키워드 검색 창 | 6장 ListView, 5장 DoubleClick | `IndexOf`, `List<T>`, `Sort` |
| `Forms/MiniWidgetForm.cs` | 미니 위젯 창 | 2장 Location·폼 이벤트, 3장 ListBox | `TopMost`, 화면 크기 구하기 |

## 학습 목표

AI를 활용해서 아래 세 가지를 이해하는 수준을 목표로 합니다.

1. 내가 공부하는 기능이 무엇인지
2. 이 코드가 어떤 의미인지
3. 내가 설명하는 기능이 어떤 흐름으로 동작하는지

- 코드를 외우거나 직접 작성할 필요는 없습니다.
- 핵심 코드 한두 곳은 가리키며 설명하고 질문에 답할 수 있게 준비합니다.
- 코드의 한글 주석을 따라 읽으면 흐름이 보입니다. 실행 화면은 [구현화면.md](구현화면.md)에서 볼 수 있습니다.
